# PPTX to PDF Converter

A simple Python utility to batch convert `.pptx` files to `.pdf` using LibreOffice in headless mode.

## Features

- Converts all `.pptx` files in a given folder to PDF
- Uses LibreOffice's command-line interface
- Supports batch conversion

## Requirements

- Python 3.x
- LibreOffice installed and added to system PATH

## Usage

```bash
python convert_pptx.py /path/to/folder
